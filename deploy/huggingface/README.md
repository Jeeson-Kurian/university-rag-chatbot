# Course Compass

Ask University of Klagenfurt curricula a question in any language. Every answer shows the
page it came from, a second AI model checks it, and the assistant says so when the
documents don't cover the question.

Source, evaluation and limitations: https://github.com/Jeeson-Kurian/university-rag-chatbot

Student hackathon prototype (AI OpenBuild 2026), not an official university service.
